# 0x0F. C - Variadic functions

## Description
This project introduces **Variadic Functions** in C programming. It covers how to use functions that accept an indefinite number of arguments using the `stdarg.h` library and the `va_start`, `va_arg`, and `va_end` macros.

## Files
* `variadic_functions.h`: Header file containing all function prototypes and the `_putchar` prototype. Include guarded.
* `0-sum_them_all.c`: Function that returns the sum of all its parameters.
